## Дипломный проект. Задание 3: UI-тесты

### Автотесты для проверки программы, которая помогает заказать бургер в Stellar Burgers

### Реализованные сценарии

Созданы UI-тесты, частично покрывающие функциональность создания заказа, взаимодействие с личным кабинетом пользователя

Отчет: `allure serve allure_results`

### Структура проекта

- `locators` - пакет, содержащий локаторы элементов
- `pages` - пакет, содержащий классы тестируемых страниц
- `tests` - пакет, содержащий тесты
- `src` - пакет, содержащий вспомогательные данные

### Запуск автотестов

**Установка зависимостей**

> `$ pip install -r requirements.txt`

**Запуск автотестов**

>  `$ pytest tests/`
